# 📖 Overview

This project is a responsive tribute webpage dedicated to **A.R. Rahman**, one of India's most celebrated music composers.

The website highlights his inspiring life journey, achievements, awards, and musical legacy through a clean and visually appealing layout.

Developed using only HTML and CSS, the project demonstrates semantic web development and responsive page design.

---

# 🎯 Project Objective

The goal of this project was to:

- Practice semantic HTML5
- Improve CSS styling skills
- Build responsive web layouts
- Create visually appealing webpages
- Learn content organization and typography
